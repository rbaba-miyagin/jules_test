# スプリントレビュー

## スプリント1

**開催日:** 2025-12-01

**参加者:**
- 開発チーム
- プロダクトオーナー（代理）

**デモ内容:**
- Postmanを使用して、以下のAPIエンドポイントの動作をデモンストレーション。
  - `POST /todos`: 新しいTODOアイテムの作成
  - `GET /todos`: TODOアイテムの一覧取得
  - `PUT /todos/:id`: TODOアイテムの完了状態の更新
  - `DELETE /todos/:id`: TODOアイテムの削除

**完了したプロダクトバックログアイテム:**
- PBI-001: ユーザーは新しいTODOアイテムを登録できる
- PBI-002: ユーザーはTODOアイテムの一覧を閲覧できる
- PBI-003: ユーザーはTODOアイテムを完了状態に更新できる
- PBI-004: ユーザーは不要になったTODOアイテムを削除できる

**ステークホルダーからのフィードバック:**
- APIの基本的な機能については問題ないことを確認。
- 次のスプリントでは、フロントエンドの実装を期待する。
